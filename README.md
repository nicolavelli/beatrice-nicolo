# Beatrice & Nicolò — Wedding website

Sito ufficiale del matrimonio di Beatrice e Nicolò — 7 dicembre 2026, Borgo Capietaglio, Pontida.

## Privacy
Questo repository è pubblico e contiene esclusivamente il codice e i contenuti destinati alla pubblicazione. Non inserire qui lista invitati, risposte RSVP, IBAN o altri dati personali/sensibili.

## Struttura
- `index.html` — contenuto e struttura della pagina
- `styles.css` — stile responsive/mobile-first
- `script.js` — micro-animazioni progressive

RSVP e dati privati verranno gestiti tramite un servizio separato.
